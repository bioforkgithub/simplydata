Model averages of "marks" for each "breakfast" (180 rows), within each "class":
Does the effect of "breakfast" depend on "class"? The interaction breakfast : class: F = 1.48, df = 2 and 174; about 23 of 100 studies would show this much if the effect were truly the same in every group (p = 0.230).

Method: the model lm(marks ~ class * breakfast), then R emmeans::emmeans(m, ~ breakfast | class) and contrast(e, method = "pairwise"), with emmeans' own adjustment for this method (none); joint_tests(m) and joint_tests(m, by = "class") for the F tests.
A large p-value does not show that there is no difference, only that the data cannot tell.
