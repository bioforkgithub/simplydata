The median is 6.00 in "pain_week_0", 5.00 in "pain_week_4" and 4.00 in "pain_week_8" (200 rows, each measured 3 times).
If the columns truly did not differ, differences this big or bigger between them would turn up in fewer than 1 in 1000 studies like this one (p < 0.0001).
Test: Friedman test (chi-square = 226, df = 2), because the columns hold numbers measured in the same rows; it compares the ranks within each row, so it does not need bell-shaped values. As R friedman.test().
Note: Kendall's W and its 95 % CI come from the R package effectsize, which is not ready here; to add them: pip install "simplydata[r]", install R, then in R install.packages("effectsize").
