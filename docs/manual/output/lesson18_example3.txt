To find a difference of 0.5 standard deviations (Cohen's d) with an 80 % chance, using a two-sided test at 0.05, you need 64 values in each group (128 in all). Method: two-sample t-test power, as R power.t.test().
Note: the calculation uses the usual equal-spread formula; table.compare_averages_of uses Welch's t-test, which is very close to it when the groups are the same size.
Cohen's rough guide calls this a medium effect (Cohen's d: 0.2 small, 0.5 medium, 0.8 large); it is only a hint, sizes from your own field are better.

To find a hazard ratio of 0.7 (in the first group the event happens 0.7 times as often at any moment as in the second) with an 80 % chance, using a two-sided log-rank test at 0.05, you need 247 events. If 30 % of the first group and 40 % of the second have the event during the study (35 % of everyone), that is 706 people (353 in each group). Method: log-rank power by Schoenfeld's (1983) formula, as R gsDesign::nEvents(); people as R powerSurvEpi::ssizeEpi.default().
Note: this assumes the hazard ratio stays the same over time (proportional hazards) and plans no recruitment time and no people lost to follow-up; plan for more people if some will drop out.
