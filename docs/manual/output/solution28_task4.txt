Model averages of "marks" for each "class" (180 rows), with "hours" held at its average (5.00):
  green: average 50.4 (95 % CI 48.2 to 52.6)
  blue: average 46.8 (95 % CI 44.6 to 49.0)
  red: average 48.2 (95 % CI 46.0 to 50.4)
Each group against the first, "green" (difference, Dunnett's adjustment (emmeans' close form, dunnettx) for 2 comparisons):
  blue minus green: difference -3.58 (95 % CI -7.14 to -0.0200); adjusted p = 0.048 (dunnettx).
  red minus green: difference -2.22 (95 % CI -5.77 to 1.34); adjusted p = 0.284 (dunnettx).
Method: the model lm(marks ~ hours + class), then R emmeans::emmeans(m, ~ class) and contrast(e, method = "trt.vs.ctrl"), with emmeans' own adjustment for this method (dunnettx).
Adjusted p-values allow for making 2 comparisons: each says how often a difference this big would turn up among all of them if the groups truly did not differ.
A large p-value does not show that there is no difference, only that the data cannot tell.
