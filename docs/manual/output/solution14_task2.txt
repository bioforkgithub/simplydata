The average "temperature" is 1.02 in Frostby, 10.1 in Rainbridge and 17.0 in Sunnyvale. Omega-squared = 0.465 (95 % CI 0.197 to 0.636): the groups explain about 46 % of the differences in "temperature".
If the groups were truly alike, differences this big or bigger between them would turn up in fewer than 1 in 1000 studies like this one (p = 0.0002).
Test: Welch's one-way ANOVA (F = 13.0, df = 2 and 20.8), the usual test for three or more averages; it does not assume the groups have the same spread. To see which groups differ: table.compare_each_pair_of("temperature", for_each_group_in="city").
